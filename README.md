# Book Vibe

**Book Vibe** is a book management web application where users can explore popular books, view detailed information about books, and organize their reading preferences.

## Features

* Browse popular books
* View detailed information about individual books
* Add books to a **Read List**
* Add books to a **Wish List**
* Sort books in the Read List and Wish List by:

  * Rating
  * Publication Year
  * Number of Pages
* Visualize the total pages of read books using a chart

## Project Overview

Book Vibe provides a simple way for users to keep track of the books they want to read and the books they have already read. Users can organize their lists using different sorting options and get a visual overview of their reading progress through a chart.
